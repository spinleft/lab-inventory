# 快速上手

十分钟在本机跑起来,并录入第一批数据。**这份文档是用来试用和评估的**,正式部署请看 [部署文档](deployment.md)。

## 起服务

需要 Docker 和 Docker Compose。

```bash
git clone https://github.com/spinleft/lab-inventory.git
cd lab-inventory
cp .env.example .env
```

编辑 `.env`,本机试用填这几行就够:

```dotenv
PUBLIC_URL=http://localhost:8080
HMAC_SECRET=a-long-enough-secret-for-local-trial-only-do-not-use-in-production
POSTGRES_PASSWORD=local-trial-password
INITIAL_ROOT_PASSWORD=local-trial-root-password

# 本机走 HTTP,不关掉的话登录后会立刻掉线
COOKIE_SECURE=false
```

```bash
docker compose up -d
docker compose logs -f backend
```

看到 `Database schema is up to date.` 就绪。打开 <http://localhost:8080>,用 `root` 和 `INITIAL_ROOT_PASSWORD` 登录。

> 上面这套值只适合本机试用。真部署时 `HMAC_SECRET` 必须是随机生成的,`COOKIE_SECURE` 必须是 `true`。

## 理解数据模型

录数据之前,先分清两个概念,不然后面会拧巴:

- **资产(Asset)**——*一类*东西的定义。比如"25.4mm 平凸透镜 f=100mm"。它有分类、参数、计量单位。
- **库存实物(Inventory Item)**——*实际存在的*那些东西。比如"在 3 号柜 2 抽屉里的那 8 片"。它有位置、数量或序列号、状态。

一个资产下面可以挂多条库存实物记录(不同批次、不同位置)。

库存实物有两种记账方式,建资产时就要选定,之后不能改:

- **按数量(quantity)**——散件、耗材。记"还有多少",支持拆分、合并。
- **按序列号(serialized)**——仪器、模块。每一台单独一条记录,各自有序列号和状态。

## 走一遍

### 1. 准备实验室

系统自带一个叫"默认实验室"的空实验室。**管理 → 实验室**,点进去改成你的实验室名字和地址。

### 2. 建一个日常账号

root 是系统根用户,权限太大,不适合日常用。

**管理 → 用户 → 新建**,角色选 `lab_admin`(实验室管理员),绑定到刚才那个实验室。之后用这个账号登录来做下面的事。

角色的区别:

| 角色 | 能做什么 |
| --- | --- |
| 系统根用户 root | 一切,包括管别的管理员。日常别用 |
| 超级管理员 super_admin | 跨实验室管理、看审计日志 |
| 实验室管理员 lab_admin | 管本实验室的一切:用户、资产、库存、打印机、联邦 |
| 普通用户 user | 本实验室的日常操作:增删改资产和库存、打标签、借用 |
| 访客 guest | 只读,可以提借用申请 |

### 3. 建计量单位

**管理 → 计量单位**。系统预置了米/厘米/毫米/英寸/件,不够用再加(比如"瓶""包""克")。

单位是按实验室隔离的:新建的实验室没有任何单位,要自己建。

### 4. 建位置树

**管理 → 位置**。按实际情况建层级,比如:

```
4号楼
└── 113 室
    ├── 光学柜
    │   ├── 1 号抽屉
    │   └── 2 号抽屉
    └── 电子柜
```

位置支持任意层级,库存实物挂在最末一级上。

### 5. 建资产分类

**管理 → 资产分类**。同样是树形:

```
光学元件
├── 透镜
└── 反射镜
```

### 6. 定义资产参数(可选)

**管理 → 资产参数**。想按"焦距""波长"这类属性检索时才需要。

参数支持数值、文本、枚举、范围四种类型,数值型可以带单位。定义好之后要**绑定到资产分类**上,这个分类下的资产才会出现这个参数。

### 7. 录第一个资产

**资产 → 新建**:

- 名称:`25.4mm 平凸透镜 f=100mm`
- 分类:光学元件 / 透镜
- 记账方式:按数量
- 计量单位:件

保存后进详情页,填参数值(焦距 100mm 之类)。

### 8. 入库

在资产详情页点**新增库存**:

- 位置:4号楼 / 113 室 / 光学柜 / 1 号抽屉
- 数量:8
- 批次号(可选):`20260816-A`

现在"库存"页面能看到这条记录了。

### 9. 打标签(可选,需要打印机)

需要一台支持网络打印的 Brother QL 系列标签机。

**管理 → 标签打印机 → 新建**,填打印机的 IP 和纸张规格,点"检测状态"确认能连上。

然后在库存条目上点**打印标签**。标签上的二维码指向这个条目,手机扫一下就能打开。

打印机接入细节见 [标签打印文档](label-printing.md)。

### 10. 试试扫码

**扫码**页面,用摄像头扫刚打出来的标签,应该直接跳到对应的库存条目。

## 常见问题

**登录后立刻退回登录页**
`.env` 里加 `COOKIE_SECURE=false`,然后 `docker compose up -d`。HTTP 访问时浏览器不会保存标了 Secure 的 Cookie。

**8080 端口被占用**
`.env` 里改 `HTTP_PORT=9090`,同时把 `PUBLIC_URL` 改成 `http://localhost:9090`。

**后端起不来说 root 还是出厂密码**
`.env` 里的 `INITIAL_ROOT_PASSWORD` 没填,或者填了但少于 8 个字符。
