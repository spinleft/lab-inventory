# 标签打印

给库存条目和资产打二维码标签,贴到实物上,之后用手机或桌面端扫码直接跳到对应记录。

## 支持的打印机

Brother QL-800 系列的网络型号,300 dpi,通过 TCP 9100 端口的原始打印协议驱动。开发时用的是 **QL-820NWB**。

同系列的其他网络型号(QL-810W、QL-1110NWB 等)协议一致,应当可用,但没有实测。USB 直连的型号(QL-700 等)**不支持**——系统是从服务端直接连打印机的网络地址,不经过任何驱动。

## 支持的纸张

| 类型 | 规格(mm) | 可打印区域(点) |
| --- | --- | --- |
| 连续纸 | 29 | 306 |
| 连续纸 | 38 | 413 |
| 连续纸 | 50 | 554 |
| 连续纸 | 62 | 696 |
| 模切标签 | 17 × 54 | 165 × 566 |
| 模切标签 | 23 × 23 | 202 × 202 |
| 模切标签 | 29 × 90 | 306 × 991 |
| 模切标签 | 62 × 29 | 696 × 271 |
| 模切标签 | 62 × 100 | 696 × 1109 |

**62 × 29 mm 模切标签**是最常用的一档,够放二维码加两三行文字。

登记打印机时填的纸张规格必须跟实际装的一致。点"检测状态"会读回打印机报告的实际纸张,不一致时界面会提示。

## 接入

### 1. 打印机联网

按打印机说明书接入有线或无线网络,给它一个**固定 IP**(在路由器上做 DHCP 保留,或者在打印机上设静态地址)。IP 变了打印就会失败。

确认服务器能连上:

```bash
nc -vz 192.168.1.50 9100
```

### 2. 登记

**管理 → 标签打印机 → 新建**:

| 字段 | 说明 |
| --- | --- |
| 名称 | 自己认得就行,比如"113 室打印机" |
| 主机 | 打印机的 IP 或主机名 |
| 端口 | 默认 9100 |
| 纸张类型 | 连续纸 / 模切标签 |
| 纸张宽度、长度 | 见上表 |

只有**实验室管理员**能登记和修改打印机。这不是随手设的门槛:主机字段是**服务端会去主动连接**的地址,能改它就能让服务器去连内网里的任意地址。同样的原因,回环地址(`127.0.0.1`)默认被拒绝,1024 以下的端口也不接受。

### 3. 验证

点**检测状态**。正常会返回打印机型号、当前装的纸张、有没有报错。

### 4. 打印

在库存条目或资产的详情页点**打印标签**,选打印机,预览确认后打印。也可以在库存列表里多选后批量打印。

普通用户和实验室管理员都能打印,访客不能。

## 标签上有什么

- **二维码**——指向这个条目的链接
- **名称**——资产名
- **序列号或批次号**(如果有)
- **位置**

二维码里编码的是:

```
<public_web_url>/scan?v=1&n=<节点 id>&l=<实验室 id>&t=item&i=<条目 id>
```

用手机相机直接扫会打开这个网址,所以 `public_web_url` 必须是用户实际能访问到的前端地址。**部署后先打一张试扫**——地址配错了的话,已经贴到实物上的标签只能全部重打。

在应用内的扫码页扫描时走的是另一条路:只读 `?` 后面的参数,不管域名是什么。这样才能扫得开联邦对端实验室打的标签——节点 id 会去匹配自己的联邦信任关系。

## 扫码

**扫码**页面用摄像头识别二维码和条形码,识别到就跳转到对应的资产或库存条目。

需要浏览器支持摄像头,并且**页面必须是 HTTPS 或 localhost**——这是浏览器的硬性限制,HTTP 页面拿不到摄像头权限。内网 HTTP 部署想用扫码,只能上 HTTPS,或者用桌面端/安卓端。

## 实现说明

标签的位图是**前端渲染**的:浏览器按纸张尺寸画好 1-bit 位图,base64 编码后发给后端。后端负责把位图转成打印机的光栅指令(含 PackBits 压缩)并通过 TCP 送过去。

这样分工的原因是排版属于展示逻辑,放在前端可以所见即所得地预览;后端只做协议转换,不需要字体和排版引擎。

相关代码:

- `backend/src/label_printing/` —— 光栅编码、状态解析、TCP 传输
- `frontend/src/modules/labels/` —— 排版、位图生成、打印对话框
- `frontend/src/shared/lib/qrPayload.ts` —— 二维码内容的格式定义,打印和扫描共用同一份

## 排查

**"无法连接到打印机"**
- 打印机开着吗?网线/WiFi 通吗?
- 服务器能连到打印机吗?容器里试:`docker compose exec backend curl -v telnet://192.168.1.50:9100`
- IP 是不是被 DHCP 改了

**"不允许的打印机地址"**
地址是回环地址,或者端口小于 1024。换成实际的局域网地址。

**打出来是空白或乱码**
纸张规格填错了。点"检测状态"看打印机实际装的是什么,改成一致。

**二维码扫不出来**
- 标签太小放不下:换大一号的纸张
- 打印头脏了或色带用尽:按说明书清洁
- 扫码页面不是 HTTPS:摄像头拿不到权限,浏览器控制台里会有报错
